# Baker's Dawgs Ordering App

Mobile-first pickup ordering app for Baker's Dawgs, 1501 Norwood St., Lenoir, NC.

## Included
- Customer menu with categories
- Add-to-order cart and automatic totals
- Customer name, phone, pickup time and special instructions
- Mobile responsive design
- Installable web-app manifest (PWA foundation)
- Cart persistence on the customer's device

## Important before launch
The checkout UI is functional as a prototype, but it intentionally does **not** transmit orders yet. Connect a secure backend/order notification service before accepting real customer orders. Add a payment processor only if online prepayment is desired.

## Menu note
The photographed sausage menu shows a handwritten $6 sign, so sausage items are currently set to $6.00. Confirm individual sausage prices before launch. Several hot-dog lines in the source photo do not visibly show separate prices; the current prototype uses $3.28 for those standard hot-dog variants based on the visible menu pricing. Confirm those prices before launch.
